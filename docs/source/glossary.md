## 1. Copilot 側の概念

| 用語 | 定義 | コード上の名前 |
|---|---|---|
| **セッション** | Copilot の 1 回の対話セッション。一意な session id を持つ | `session_id` |
| **エントリポイント** | セッションを起動した経路 | `entrypoint`: `cli_interactive` / `cli_background` / `vscode` / `coding_agent` / `unknown` |
| **サブエージェント実行** | セッションが起動した下位エージェント・委任タスクの 1 実行。親子関係を持ち N 段の木を成す | `subagent_runs` の 1 行 |
| **ターン (レコード)** | セッションログの 1 行 = 1 イベント | `turn_index` の 1 行 |
| **トランスクリプト** | セッションの発話・ツール呼び出し・ツール出力が記録された JSONL 形式のログ | `events.jsonl` |
| **AI Credit** | Copilot の従量課金の単位。トークン消費 × モデル別レートで消費される | `credits` |
| **nano-AIU** | Copilot SDK がコストを報告する単位。**10⁹ で割ると AI Credit** | `nano_aiu` / `total_nano_aiu` |
| **クォータ** | プラン契約に含まれる利用枠。SDK の `account.getCurrentAuth` が返す `quota_snapshots` の単位 | `QuotaGauge.kind` |
| **コンテキストウィンドウ** | 1 セッションが保持できるトークンの上限 | `context_used` / `context_limit` |
| **利用枠到達イベント** | クレジット枯渇・レート制限・セッション上限に達した記録 | `quota_events` |

## 2. プロジェクト側の概念

| 用語 | 定義 | コード上の名前 |
|---|---|---|
| **`path_key`** | 正規化済みパス (小文字化 + 区切りを `\` に統一 + 末尾区切り除去)。**プロジェクトの一意キー** | `path_key` |
| **`root_path`** | プロジェクトのルート。**git の判定対象はこちら** (FR-P-44) | `root_path` |
| **`working_dir`** | 起動コマンドを実行するディレクトリ。ルートと異なることがある (FR-P-12) | `working_dir` |
| **種別** | マニフェストの存在有無だけで決まるプロジェクト分類 | `ProjectKind` |
| **手動調整 (override)** | 表示名 / 起動コマンド / 作業ディレクトリ / 並び順 / 非表示 / アーカイブ の上書き | `project_overrides` |
| **スキャン対象フォルダ** | 直下 1 階層を走査する対象。ユーザーが登録する | `project_scan_folders` |
| **dev サーバー** | プロジェクトの開発サーバー。本アプリが起動 / 停止する唯一のプロセス | `DevState` |
| **フォルダ名フォールバック** | 完全一致が無いとき、3 条件すべて成立時に限りフォルダ名で履歴を照合する仕組み | `matched_by: 'folder_name_fallback'` |

## 3. 実装用語

| 用語 | 定義 |
|---|---|
| **差分インデックス** | ファイルの記録済みバイトオフセット以降だけをパースする仕組み。系統 (2) |
| **ライブ監視** | 2 秒ポーリングで稼働状況だけを見る仕組み。系統 (1)。**永続化しない** |
| **利用枠取得** | SDK / REST から枠を取る仕組み。系統 (3)。**唯一ネットワークを使う** |
| **末尾断片** | 改行で終わらない書きかけの最終行。確定分から除外する (FR-C-05) |
| **全再パース** | ファイルサイズが記録より小さくなったときの、先頭からのやり直し (FR-C-06) |
| **観測時刻 (`observed_at`)** | **値が変化したときだけ更新される時刻。**鮮度判定はこれを使う (FR-C-86) |
| **取得時刻 (`received_at`)** | 取得しに行った時刻。**鮮度判定に使ってはいけない** |
| **出所 (source)** | 値がどこから来たか。`実値 (sdk/rest)` / `推定` / `取得不可` の 3 状態 |
| **降格** | 利用枠の取得経路を A → B → C と落としていくこと |
| **祖先保護** | 折りたたみ時に、稼働中の子孫を持つノードを畳まない規則 (FR-C-116) |
| **孤児** | 親が見つからないサブエージェント行。**捨てずにルート直下に置く** (FR-C-113) |
| **スナップショット** | ある時点の状態一式。タブ切替時の即描画に使う (FR-C-164) |
| **プローブ** | 実データ・実 API に対して数字を出すだけの読み取り専用スクリプト (NFR-52) |

## 4. 紛らわしい対の区別

| A | B | 違い |
|---|---|---|
| **拒否 (`declined`)** | **失敗 (`completed`)** | 親が呼び出しを拒否した / 実際に起動して終わった (FR-C-27) |
| **暫定応答** | **完了通知** | 「起動しました」という即時の返り / 本当の終了通知。**暫定を完了扱いしない** (FR-C-24) |
| **`root_path`** | **`working_dir`** | git を見る場所 / コマンドを実行する場所 (FR-P-44 / FR-P-12) |
| **`received_at`** | **`observed_at`** | 取りに行った時刻 / 値が変わった時刻。**鮮度は後者** (FR-C-86) |
| **実値** | **推定** | SDK / API 由来 / 過去実績との相対値。**同じ枠で混ぜない** (FR-C-84) |
| **ツール実行中** | **許可待ち** | **区別できない。**UI で断定しない (FR-C-46) |
| **累計セッション数** | **保持されているセッション数** | 前者は自動削除があると原理的に取れない (NFR-44) |
| **稼働中サブエージェントの集合** | **その件数** | **集合が正。件数は length で導出する** (FR-C-51) |
| **非表示 (hidden)** | **アーカイブ (archived)** | 一覧から隠す / 終わったものとして畳む。別のフラグ |

## 5. 使わない言葉

| 使わない | 理由 | 代わりに |
|---|---|---|
| 「同期する」 | Copilot 側へ書き込む印象を与える。**読み取り専用が不変条件** | 「読み込む」「インデックスする」 |
| 「キャッシュを更新」 (利用枠について) | 鮮度の主語が取得時刻に見える | 「観測を更新」 |
| 「エラー」 (未インデックスのセッションについて) | 正常系である (FR-C-57) | 「まだ記録がありません」 |
| 「累計」 (セッション数について) | 取得できない可能性がある (NFR-44) | 「保持されている」 |
| 「消費率」だけの表示 | 従量課金では額が判断単位 (FR-C-89) | 「率 + 額」 |
