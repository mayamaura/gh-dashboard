## 0. 全体の原則

| 原則 | 実装への影響 |
|---|---|
| **推測を事実として見せない** | 推定値・フォールバック照合・区別できない状態には必ずラベルを出す (NFR-40〜42) |
| **取れないものは「取れない」と出す** | 0% のゲージや空欄で埋めない。「何をすれば取れるか」を添える (FR-C-83) |
| **画面を見ていないときのコストをゼロにする** | タブ離脱・最小化ですべてのタイマーが止まる (NFR-12) |
| **タブ切替で進行中の処理が「消えて」見えない** | 進行状態は `appStore` に置く (FR-C-161) |
| **切替時は即描画してから裏で最新化** | スナップショットキャッシュ (FR-C-164 / FR-P-86) |

## 1. シェル

```
┌──────────────────────────────────────────────────────────────┐
│ [ Copilot ] [ プロジェクト ]        最終インデックス: 12 秒前   │
│                                     利用枠: SDK / 2 分前  [更新] │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│                        タブの中身                              │
│                                                               │
└──────────────────────────────────────────────────────────────┘
```

ヘッダーの内容はタブごとに変わる。

| タブ | ヘッダー |
|---|---|
| Copilot | 最終インデックス (相対時刻) / 利用枠の取得経路と最終取得時刻 / 更新ボタン (FR-C-160) |
| プロジェクト | 最終スキャン (相対時刻) / すべて停止 / 更新 (FR-P-85) |

「インデックス中」バッジは**手動更新のときだけ**出す。自動実行では出さず、「最終インデックス: N 秒前」の更新を鮮度の保証とする (FR-C-60)。10 秒ごとの点滅は視覚ノイズになる。

### 2.1 利用枠ゲージ (FR-C-80〜95)

| 要素 | 規則 |
|---|---|
| 出所ラベル | `実値` / `推定` / `取得不可` を**必ず**出す (FR-C-81) |
| 「推定」の説明 | 「過去実績との相対値であり、提供元が課金している実際の消費率ではない」を添える (FR-C-82) |
| 「取得不可」 | 何をすれば取れるか (認証が必要 / SDK が見つからない / 対象プランでない) を出す (FR-C-83) |
| 金額 | 率だけでなく額も併記 (`$6.20 / $10.00 (62%)`) (FR-C-89) |
| 超過 | **100% でクランプしない。**超過額を別建てで明示 (FR-C-90) |
| 無制限 | `entitlement = -1` は率ではなく「無制限」(FR-C-131) |
| 色 | 90% 以上 = 危険 / 70% 以上 = 警告 / それ未満 = 通常 (FR-C-88) |
| 鮮度 | 観測からの経過時間を表示。15 分超で警告色 (FR-C-87) |
| リセット | 月次は日付、短期は残り時間 (FR-C-91) |

**枠ごとに独立して評価する。**ある枠が実値でも、取れなかった別の枠に推定を混ぜない (FR-C-84)。

### 2.2 セッションカード (FR-C-53)

出す情報: フォルダ名 / エントリポイントバッジ / タイトル / 活動状態ドット / モデル名 / 稼働時間 / 最終活動 (相対時刻) / コンテキストウィンドウ使用率 / セッション消費クレジット / サブエージェント数バッジ。

活動状態の 5 値と表示:

| 値 | ドット | 文言 | 補足 |
|---|---|---|---|
| `generating` | 動 | 生成中 | |
| `tool_running` | 動 | **ツール実行中** | **「許可待ちかもしれない」はツールチップに書く。文言で断定しない (FR-C-46 / NFR-42)** |
| `waiting_input` | 静 | 入力待ち | |
| `subagent_running` | 動 | サブエージェント実行中 | |
| `unknown` | 静 | 不明 | 空欄にしない |

| 規則 | 詳細 |
|---|---|
| タイトルのフォールバック | インデックス済みタイトル → セッションストア / 状態ファイル由来の名前 (FR-C-54) |
| 30 分以上アイドル | 既定で非表示。トグルで表示 (FR-C-55) |
| 「指示を出したら再表示」 | **状態を持たない。**最終活動時刻の判定が自然に戻ることで満たす (FR-C-55) |
| 展開 | インラインで系統図。**サブエージェント稼働中は自動展開** (FR-C-56) |
| 自動展開の抑止 | 手動で閉じた場合と取得に失敗した場合。**抑止が無いと 2 秒ループになる** (FR-C-56) |
| 未インデックス | 「まだ記録がありません」と穏やかに表示。**赤いエラーを出さない** (FR-C-57) |
| サブエージェント数 | **ライブ集合の length。**別カウントを持たない (FR-C-51) |

### 2.3 系統図とガント (FR-C-112〜118)

| 規則 | 詳細 |
|---|---|
| 木の構築 | `parent_agent_id` を辿る。**孤児はルート直下。循環をガード** (FR-C-113) |
| 深さ | 生データの `depth` を信じない (FR-C-114) |
| 行の並び | **系統図とガントで同じ木構築結果を使う** (FR-C-114) |
| ライブ側の稼働判定 | **ライブ集合を優先。**照合できない行 (拒否済み・メタ未読) は DB の状態にフォールバック (FR-C-115) |
| ライブ側の折りたたみ | 完了したエージェントを各階層で 1 行に畳む。**稼働中の子孫を持つノードは畳まない (祖先保護)** (FR-C-116) |
| 稼働中が 0 件のとき | 折りたたみは維持し「稼働中のエージェントはありません」と明示 (FR-C-116) |
| 振り返り側 | **全件表示** (ライブ集合を渡さない限り表示が変わらない設計) (FR-C-117) |
| ガントの横軸 | セッションの開始〜終了 (稼働中なら現在時刻)。利用枠到達イベントを縦マーカーで重畳 (FR-C-118) |
| mtime 由来の遅れ | 最大 N 秒の遅れがあることを既知の制約として受け入れ、**UI で断定しない** (FR-C-52) |

### 2.4 本文ビューア (FR-C-119/120)

- タイムライン上限 1000 件。初期 150 件、「もっと見る」で 150 件ずつ
- **行クリックでその 1 レコードだけをシーク読み**して整形表示
- 上限 512KB。オフセットがファイル範囲外なら「インデックスを再実行してください」と案内
- 系統図・ガント・ビューアの選択とホバーを相互連動 (FR-C-121)

## 3. プロジェクトタブ

```
┌─ [検索____] 種別▾ □非表示も □アーカイブ隠す □起動中のみ ──────┐
│                     最終スキャン: 3 分前  [すべて停止] [更新]    │
├──────────────────────────────────────────────────────────────┤
│ ● ◆ gh-dashboard        main ● Tauri   3 分前  http://…:5173  ⏹ ⋮│
│ ○   notes-app  [非表示]  dev    Next.js  昨日   npm run dev   ▶ ⋮│
│ ○   old-thing  [アーカイブ]  —  その他   —      起動不可       ⋮│
├──────────────────────────────────────────────────────────────┤
│ 詳細パネル                                                     │
└──────────────────────────────────────────────────────────────┘
```

2 ペイン構成 (一覧 + 詳細)。**絞り込みはすべてフロント側で完結**させ、バックエンドに再問い合わせしない (FR-P-81)。

### 3.1 一覧行 (FR-P-83)

出す情報: dev 状態ドット / Copilot 稼働中バッジ / 表示名 (+ 非表示・アーカイブバッジ) / git ブランチと未コミット変更ドット / 種別 / 最終利用日時 (相対表示) / 稼働中の URL または起動コマンド / 起動・停止ボタン / 外部ツールメニュー。

| 規則 | 詳細 |
|---|---|
| 並べ替え | 最終利用日時 (既定。**履歴なしは末尾に沈める**) / 名前 / 種別。同率は表示名昇順 (FR-P-82) |
| 種別「その他」 | **一覧から隠さない** (FR-P-13) |
| 起動不可 | 隠さず、ボタンを無効化して**理由を表示** (FR-P-22) |
| 行内メニュー | クリック位置から座標計算して固定配置で描く。**横スクロールコンテナの overflow クリッピングを避ける** (FR-P-88) |

### 3.2 詳細パネル (FR-P-84)

パス / 種別 / 作業ディレクトリ / 起動コマンド候補 / 外部ツールボタン列 / dev サーバー状態と操作とログ / git 状態 / Copilot 利用状況 / 起動不可の理由 / 手動調整フォーム。

| 要素 | 規則 |
|---|---|
| dev 状態 | `停止中 / 起動中 / 稼働中(URL, PID, 開始時刻) / 終了(終了コード) / 失敗(理由)` の 5 状態 (FR-P-60) |
| ログ | メモリ上 500 行のみ。200〜300ms バッファで流れてくる (FR-P-64/65) |
| git | `.git` が無ければ「git 情報なし」。detached HEAD はブランチ名なし (FR-P-41/42) |
| Copilot 利用状況 | 履歴が無ければ**セクションごと出さない。**空欄で埋めない (FR-P-58) |
| フォールバック照合 | **「旧パスの履歴 (フォルダ名で照合)」と明示する** (FR-P-53 / NFR-41) |
| 手動調整 | 表示名 / 起動コマンド上書き / 作業ディレクトリ上書き / 並び順 / 非表示 / アーカイブ (FR-P-30) |
| 作業ディレクトリ上書き | 保存時に実在検証。通らなければ**拒否して保存しない** (FR-P-32) |

### 3.3 外部ツール (FR-P-70)

VS Code で開く / エクスプローラーで開く / ターミナルで開く / Copilot CLI をそのディレクトリで起動 / (稼働中かつ URL 検出済みなら) ブラウザで開く。

失敗時は「PATH に無い」等の**具体的な対処**を案内する (FR-P-73)。

## 5. アニメーション (FR-C-162/163)

| 設定 | 挙動 |
|---|---|
| `自動` (既定) | OS の「動きを減らす」設定 (`prefers-reduced-motion`) に追随 |
| `入` | 常に有効 |
| `切` | 常に無効 |

設定は永続化する。アニメーションは `transform` / `opacity` / `stroke-dashoffset` / `filter` に限定 (GPU 合成される)。常時稼働時の UI プロセスの CPU 増分は 1 コア換算 +2 ポイント以内 (NFR-05)。

## 6. 文言のルール

| 状況 | 使う | 使わない |
|---|---|---|
| ツール実行中か許可待ちか不明 | 「ツール実行中」 | 「許可待ち」「応答待ち」(断定) |
| フォルダ名で照合した履歴 | 「旧パスの履歴 (フォルダ名で照合)」 | 何も書かない |
| 推定した消費率 | 「推定 (過去実績比)」 | 「62%」だけ |
| 取得できなかった | 「取得できませんでした — 認証が必要です」 | 「0%」「—」だけ |
| 保持されているセッション数 | 「保持されているセッション 128 件」 | 「累計セッション 128 件」(NFR-44) |
| 集計から除外があった | 「12 件を読み飛ばしました」 | 無言で欠落 (NFR-43) |
| 金額 | 「$6.20 (概算)」+ 注記 | 「$6.20」だけ (NFR-45) |
