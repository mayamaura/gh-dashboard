## 進め方

- タスク ID は `T-<段階>.<連番>`。**段階を飛ばさない**
- 1 タスク = 1 コミット を目安にする
- 着手前に、そのタスクの「要求」列の ID を [要求仕様](requirements.html) で読む
- 完了時に [トレーサビリティ](traceability.html) の該当行を埋める
- 状態は `未着手` / `進行中` / `完了` / `保留(OQ待ち)`

> [!注意]
> **段階 0 を飛ばさない。** OQ-02 (バイトオフセット方式が成立するか) と OQ-06 (利用枠が SDK で取れるか) の結論次第で、段階 4 と段階 6 の設計が根本から変わる。推測で先に進めると、書いたコードがまるごと無駄になる。
