3. 実装用語

用語定義
差分インデックスファイルの記録済みバイトオフセット以降だけをパースする仕組み。系統 (2)
ライブ監視2 秒ポーリングで稼働状況だけを見る仕組み。系統 (1)。永続化しない
利用枠取得SDK / REST から枠を取る仕組み。系統 (3)。唯一ネットワークを使う
末尾断片改行で終わらない書きかけの最終行。確定分から除外する (FR-C-05)
全再パースファイルサイズが記録より小さくなったときの、先頭からのやり直し (FR-C-06)
観測時刻 (observed_at)値が変化したときだけ更新される時刻。鮮度判定はこれを使う (FR-C-86)
取得時刻 (received_at)取得しに行った時刻。鮮度判定に使ってはいけない
出所 (source)値がどこから来たか。実値 (sdk/rest) / 推定 / 取得不可 の 3 状態
降格利用枠の取得経路を A → B → C と落としていくこと
祖先保護折りたたみ時に、稼働中の子孫を持つノードを畳まない規則 (FR-C-116)
孤児親が見つからないサブエージェント行。捨てずにルート直下に置く (FR-C-113)
スナップショットある時点の状態一式。タブ切替時の即描画に使う (FR-C-164)
プローブ実データ・実 API に対して数字を出すだけの読み取り専用スクリプト (NFR-52)

4. 紛らわしい対の区別

AB違い
拒否 (declined)失敗 (completed)親が呼び出しを拒否した / 実際に起動して終わった (FR-C-27)
暫定応答完了通知「起動しました」という即時の返り / 本当の終了通知。暫定を完了扱いしない (FR-C-24)
root_pathworking_dirgit を見る場所 / コマンドを実行する場所 (FR-P-44 / FR-P-12)
received_atobserved_at取りに行った時刻 / 値が変わった時刻。鮮度は後者 (FR-C-86)
実値推定SDK / API 由来 / 過去実績との相対値。同じ枠で混ぜない (FR-C-84)
ツール実行中許可待ち区別できない。UI で断定しない (FR-C-46)
累計セッション数保持されているセッション数前者は自動削除があると原理的に取れない (NFR-44)
稼働中サブエージェントの集合その件数集合が正。件数は length で導出する (FR-C-51)
非表示 (hidden)アーカイブ (archived)一覧から隠す / 終わったものとして畳む。別のフラグ

5. 使わない言葉

使わない理由代わりに
「同期する」Copilot 側へ書き込む印象を与える。読み取り専用が不変条件「読み込む」「インデックスする」
「キャッシュを更新」 (利用枠について)鮮度の主語が取得時刻に見える「観測を更新」
「エラー」 (未インデックスのセッションについて)正常系である (FR-C-57)「まだ記録がありません」
「累計」 (セッション数について)取得できない可能性がある (NFR-44)「保持されている」
「消費率」だけの表示従量課金では額が判断単位 (FR-C-89)「率 + 額」
