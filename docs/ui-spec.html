0. 全体の原則

原則実装への影響
推測を事実として見せない推定値・フォールバック照合・区別できない状態には必ずラベルを出す (NFR-40〜42)
取れないものは「取れない」と出す0% のゲージや空欄で埋めない。「何をすれば取れるか」を添える (FR-C-83)
画面を見ていないときのコストをゼロにするタブ離脱・最小化ですべてのタイマーが止まる (NFR-12)
タブ切替で進行中の処理が「消えて」見えない進行状態は appStore に置く (FR-C-161)
切替時は即描画してから裏で最新化スナップショットキャッシュ (FR-C-164 / FR-P-86)

2.1 利用枠ゲージ (FR-C-80〜95)

要素規則
出所ラベル実値 / 推定 / 取得不可 を必ず出す (FR-C-81)
「推定」の説明「過去実績との相対値であり、提供元が課金している実際の消費率ではない」を添える (FR-C-82)
「取得不可」何をすれば取れるか (認証が必要 / SDK が見つからない / 対象プランでない) を出す (FR-C-83)
金額率だけでなく額も併記 ($6.20 / $10.00 (62%)) (FR-C-89)
超過100% でクランプしない。超過額を別建てで明示 (FR-C-90)
無制限entitlement = -1 は率ではなく「無制限」(FR-C-131)
色90% 以上 = 危険 / 70% 以上 = 警告 / それ未満 = 通常 (FR-C-88)
鮮度観測からの経過時間を表示。15 分超で警告色 (FR-C-87)
リセット月次は日付、短期は残り時間 (FR-C-91)

枠ごとに独立して評価する。ある枠が実値でも、取れなかった別の枠に推定を混ぜない (FR-C-84)。

2.2 セッションカード (FR-C-53)

出す情報: フォルダ名 / エントリポイントバッジ / タイトル / 活動状態ドット / モデル名 / 稼働時間 / 最終活動 (相対時刻) / コンテキストウィンドウ使用率 / セッション消費クレジット / サブエージェント数バッジ。

活動状態の 5 値と表示:

値ドット文言補足
generating動生成中
tool_running動ツール実行中「許可待ちかもしれない」はツールチップに書く。文言で断定しない (FR-C-46 / NFR-42)
waiting_input静入力待ち
subagent_running動サブエージェント実行中
unknown静不明空欄にしない
規則詳細
タイトルのフォールバックインデックス済みタイトル → セッションストア / 状態ファイル由来の名前 (FR-C-54)
30 分以上アイドル既定で非表示。トグルで表示 (FR-C-55)
「指示を出したら再表示」状態を持たない。最終活動時刻の判定が自然に戻ることで満たす (FR-C-55)
展開インラインで系統図。サブエージェント稼働中は自動展開 (FR-C-56)
自動展開の抑止手動で閉じた場合と取得に失敗した場合。抑止が無いと 2 秒ループになる (FR-C-56)
未インデックス「まだ記録がありません」と穏やかに表示。赤いエラーを出さない (FR-C-57)
サブエージェント数ライブ集合の length。別カウントを持たない (FR-C-51)

2.3 系統図とガント (FR-C-112〜118)

規則詳細
木の構築parent_agent_id を辿る。孤児はルート直下。循環をガード (FR-C-113)
深さ生データの depth を信じない (FR-C-114)
行の並び系統図とガントで同じ木構築結果を使う (FR-C-114)
ライブ側の稼働判定ライブ集合を優先。照合できない行 (拒否済み・メタ未読) は DB の状態にフォールバック (FR-C-115)
ライブ側の折りたたみ完了したエージェントを各階層で 1 行に畳む。稼働中の子孫を持つノードは畳まない (祖先保護) (FR-C-116)
稼働中が 0 件のとき折りたたみは維持し「稼働中のエージェントはありません」と明示 (FR-C-116)
振り返り側全件表示 (ライブ集合を渡さない限り表示が変わらない設計) (FR-C-117)
ガントの横軸セッションの開始〜終了 (稼働中なら現在時刻)。利用枠到達イベントを縦マーカーで重畳 (FR-C-118)
mtime 由来の遅れ最大 N 秒の遅れがあることを既知の制約として受け入れ、UI で断定しない (FR-C-52)

2.4 本文ビューア (FR-C-119/120)

  • タイムライン上限 1000 件。初期 150 件、「もっと見る」で 150 件ずつ
  • 行クリックでその 1 レコードだけをシーク読みして整形表示
  • 上限 512KB。オフセットがファイル範囲外なら「インデックスを再実行してください」と案内
  • 系統図・ガント・ビューアの選択とホバーを相互連動 (FR-C-121)

3.1 一覧行 (FR-P-83)

出す情報: dev 状態ドット / Copilot 稼働中バッジ / 表示名 (+ 非表示・アーカイブバッジ) / git ブランチと未コミット変更ドット / 種別 / 最終利用日時 (相対表示) / 稼働中の URL または起動コマンド / 起動・停止ボタン / 外部ツールメニュー。

規則詳細
並べ替え最終利用日時 (既定。履歴なしは末尾に沈める) / 名前 / 種別。同率は表示名昇順 (FR-P-82)
種別「その他」一覧から隠さない (FR-P-13)
起動不可隠さず、ボタンを無効化して理由を表示 (FR-P-22)
行内メニュークリック位置から座標計算して固定配置で描く。横スクロールコンテナの overflow クリッピングを避ける (FR-P-88)

3.2 詳細パネル (FR-P-84)

パス / 種別 / 作業ディレクトリ / 起動コマンド候補 / 外部ツールボタン列 / dev サーバー状態と操作とログ / git 状態 / Copilot 利用状況 / 起動不可の理由 / 手動調整フォーム。

要素規則
dev 状態停止中 / 起動中 / 稼働中(URL, PID, 開始時刻) / 終了(終了コード) / 失敗(理由) の 5 状態 (FR-P-60)
ログメモリ上 500 行のみ。200〜300ms バッファで流れてくる (FR-P-64/65)
git.git が無ければ「git 情報なし」。detached HEAD はブランチ名なし (FR-P-41/42)
Copilot 利用状況履歴が無ければセクションごと出さない。空欄で埋めない (FR-P-58)
フォールバック照合「旧パスの履歴 (フォルダ名で照合)」と明示する (FR-P-53 / NFR-41)
手動調整表示名 / 起動コマンド上書き / 作業ディレクトリ上書き / 並び順 / 非表示 / アーカイブ (FR-P-30)
作業ディレクトリ上書き保存時に実在検証。通らなければ拒否して保存しない (FR-P-32)

3.3 外部ツール (FR-P-70)

VS Code で開く / エクスプローラーで開く / ターミナルで開く / Copilot CLI をそのディレクトリで起動 / (稼働中かつ URL 検出済みなら) ブラウザで開く。

失敗時は「PATH に無い」等の具体的な対処を案内する (FR-P-73)。

5. アニメーション (FR-C-162/163)

設定挙動
自動 (既定)OS の「動きを減らす」設定 (prefers-reduced-motion) に追随
入常に有効
切常に無効

設定は永続化する。アニメーションは transform / opacity / stroke-dashoffset / filter に限定 (GPU 合成される)。常時稼働時の UI プロセスの CPU 増分は 1 コア換算 +2 ポイント以内 (NFR-05)。

6. 文言のルール

状況使う使わない
ツール実行中か許可待ちか不明「ツール実行中」「許可待ち」「応答待ち」(断定)

推定した消費率「推定 (過去実績比)」「62%」だけ
取得できなかった「取得できませんでした — 認証が必要です」「0%」「—」だけ
