## 絶対に守ること

| # | 規則 | 根拠 |
|---|---|---|
| 1 | **`invoke` を書いてよいのは `src/ipc/commands.ts` だけ。** `listen` は `src/ipc/events.ts` だけ。ページから直接呼ばない | IR-31 |
| 2 | `listen` の購読解除を必ず返し、必ず呼ぶ。積み上がると 2 秒ポーリングが多重発火する | — |
| 3 | **2 秒ポーリング経路で呼んでよいのは `liveStatusGet` だけ。** `usageTodayGet` / `quotaGet` を混ぜない | INV-4 / FR-C-103 / FR-C-135 |
| 4 | ポーリングの起動条件は `useIsViewing()` 1 つに集約する。タブ離脱と**最小化**の両方で止まること。`visibilitychange` だけに頼らない | FR-C-43 |
| 5 | **長時間処理の進行状態をページのローカル state に置かない。** `src/store/appStore.ts` に置く。ローカルに置くとタブ切替で「処理は続いているのに表示だけ戻る」 | FR-C-161 |
| 6 | タブを開いた瞬間はキャッシュ済みスナップショットを即描画し、裏で最新化する | FR-C-164 / FR-P-86 |
| 7 | 絞り込み・並べ替えはフロントで完結させる。バックエンドに再問い合わせしない | FR-P-81 |
| 8 | **外部チャートライブラリを追加しない。**自前 SVG で描く | ADR-0005 / FR-C-163 |
| 9 | アニメーションは `transform` / `opacity` / `stroke-dashoffset` / `filter` だけ | FR-C-163 / NFR-05 |
| 10 | 系統図とガントは**同じ木構築結果**を使う。生データの `depth` を信じない | FR-C-114 |
| 11 | 行内メニューはクリック位置から座標計算して固定配置で描く (横スクロールの overflow クリッピングを避ける) | FR-P-88 |
| 12 | 依存パッケージを足さない。足したくなったら止めて相談する | NFR-13 |

## 文言 — ここが一番間違えやすい

**取れないものを 0 や空欄で埋めない。推測を事実として見せない。**

| 状況 | 書く | 書かない |
|---|---|---|
| ツール実行中か許可待ちか不明 | 「ツール実行中」+ 補足はツールチップ | 「許可待ち」(断定) |
| フォルダ名で照合した履歴 | 「旧パスの履歴 (フォルダ名で照合)」 | 何も書かない |
| 推定した消費率 | 「推定 (過去実績比)」+ 但し書き | 「62%」だけ |
| 取得できなかった | 「取得できませんでした — 認証が必要です」 | 「0%」「—」だけ |
| セッション数 | 「保持されているセッション N 件」 | 「累計セッション N 件」 |
| 集計から除外があった | 「N 件を読み飛ばしました」 | 無言で欠落 |
| 金額 | 「$6.20 (概算)」+ 注記 | 「$6.20」だけ |
| 履歴が無いプロジェクト | セクションごと出さない | 0 で埋めた行 |

対応する整形関数は `src/lib/format.ts` にあります。**自分で文言を作る前に、そこに関数が無いか確認してください。**
